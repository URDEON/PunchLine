# Rustcrawler

Modelo proporcionado por el usuario en el adjunto
`Meshy_AI_Rustcrawler_1018182955_generate.glb.glb.txt`; el contenido es GLB binario.
`Rustcrawler.glb` conserva exactamente esos bytes. Las dos imágenes JPEG son sus
texturas extraídas por el importador de Godot.

Para el juego, `res://scripts/rustcrawler_rig.gd` conserva la geometría y las texturas
y genera una piel utilizable de seis patas con dos articulaciones cada una. El skin
original no contiene reposos/ponderaciones adecuados para esa caminata. No se usan
animaciones prefabricadas ni servicios externos para moverlo.
